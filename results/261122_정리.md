# 11/22 실측 무게중심(x −11.9 mm) 반영 + 관성 비교 (김수민)

선배 피드백(가제보_수정요청_피드백_1122) 반영. 무게는 실측 2,588 g 대신 **2,600 g 유지**(선배 지시), 무게중심 x **−11.9 mm**(11/22 CAD·실측, 가제보 좌표로 변환한 값), 실제 모터 AIR2216 II. 무게중심 z는 −49.6 mm 유지(기준면 확인 필요).

## 결론
- 무게중심을 −14 → −11.9 mm로 옮기니 앞뒤 모터 차이가 줄고(호버 0.081 → 0.066), 여유 시험 모터 최대가 0.832 → 0.790으로 내려감. 호버 스로틀은 무게가 같아서 56.8 %로 같음
- 최악 조건(배터리 14.4 V + 손실 10 %)은 11/21과 같음: 67.1 %, 급상승 때 모터 1.000·포화 0.2 % → 비행 막바지 여유 적음 그대로
- 관성을 CAD 값으로 넣으면 모터 최대 0.790 → 0.848, 기울기 최대 11.5° → 12.4°로 조금 커짐. 판정은 정상 그대로. 호버 흔들림·빠른 옆 이동 넘침은 거의 같음
- 바꾼 PX4 파라미터: CA_ROTOR 앞 0.188 → 0.186, 뒤 −0.160 → −0.162, EKF2_OF·RNG_POS_X 0.094 → 0.092, EKF2_IMU_POS_X 0.014 → 0.012 (MC_·MPC_ 게인 그대로)

## 1. 호버 (30 s, 실제 모터) — `261122_hover_cg-11.9_air2216/2600g`
| 항목 | 11/20 (무게중심 −14 mm) | 11/22 (−11.9 mm) |
|---|---|---|
| 호버 스로틀 (계산) | 56.7 % (56.9) | 56.8 % (56.9) |
| 모터 출력 앞 / 뒤 | 0.527 / 0.608 (차이 0.081) | 0.535 / 0.601 (차이 0.066) |
| 피치 토크 명령 평균 | +0.0073 | +0.0084 |
| 자세 흔들림 최대 (롤 / 피치) | 0.05° | 0.06° / 0.04° |

- 앞뒤 차이가 줄어든 건 무게중심이 기체 가운데로 2.1 mm 와서 뒤 모터 부담이 준 것
- 피치 토크는 둘 다 0.01 아래라 무게중심 보정은 맞음 (0.0073 ↔ 0.0084 차이는 1회 비행 편차 수준)

- 관성: 근사(PX4 기본 x500 × 무게 비율) ixx 0.0275, iyy 0.0275, izz 0.0507 → CAD ixx 0.0450, iyy 0.0453, izz 0.0424. CAD 값 = 엑셀(택배 제외) 0.0325 / 0.0328 / 0.0424 + 택배 200 g을 무게중심 아래 0.25 m로 본 0.0125 (ixx·iyy)
- 롤·피치 관성이 약 64 % 커져서 같은 기울기 변화에 모터 앞뒤 차이를 더 크게 씀 → 모터 최대 +0.058, 기울기 +0.9°. 여유는 여전히 충분 (포화 0)
- 빠른 옆 이동 넘침은 관성과 상관없이 같음 → 위치 제어 반응 문제 (11/21 결론 그대로, 실기체 튜닝 때 볼 항목. 미션 속도 0.8 m/s에서는 문제없음)
- 관성 근사 쪽 check_overshoot의 "멈춘 뒤 실제 0.00 m"는 분석 도구 오류(실제 위치 기록 시간 순서) → 도구 수정함. 넘침 값은 정상
